KNP-26 §5.02 · RPAS-26 6.03 · trust nothing, recompute

Verify This Desk

Everything this site publishes recomputes from two public files. Below: the two commands that audit the whole record, and a browser tool that recomputes any single sealed Kall — WebCrypto, locally, nothing sent anywhere. The desk is not consulted and could not interfere if it wanted to.

The whole desk, one command each

Two reference verifiers — Python standard library, no account, no material from this desk — take the public URLs and return a conformance verdict with paragraph citations: every seal recomputed, every figure rederived from the records, every finding read off the record's own face.

python knp_verify.py  https://raw.githubusercontent.com/OccultusTheoretician/netz/main/docs/kalls_hashlog.json
python rpas_verify.py https://raw.githubusercontent.com/OccultusTheoretician/netz/main/docs/ledger.json

Both live in the repository (knp_verify.py, rpas_verify.py). Save a snapshot of either file today and add --previous your_snapshot.json on any later run to prove nothing sealed was deleted or restated — a changed probability on a sealed row fails as hard as an altered hash. Run --selftest first if you are implementing independently; the construction vectors are the interoperability contract. A NONCONFORMANT verdict against this desk publishes like any other finding.

What a match proves — and what it does not

A match proves this exact content existed, unedited, at the sealed timestamp — before the outcome. It does not prove the call was wise, that resolution was fair, or anything about the sealed-but-unrevealed remainder. Per KNM 6.03 those discretions survive the mechanism and are disclosed, not hidden. The count of what remains dark is public: that is the whole design.

The plate — a lock published before its key

On the back wall of the konsole vault hangs a sealed plate: a one-time-pad ciphertext with the SHA-256 of its key and of its plaintext committed beside it. It has no solve — every plaintext of that length is an equally consistent decode, which is the construction, not a boast. The decoder below shipped before the key exists. The day the key publishes, paste it here and your own browser opens the plate: XOR, then both hash checks, locally. The desk is not consulted at its own reveal.
