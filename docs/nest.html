No faculty ranking — by rule

Per KNP 6.05 the Nest must not rank committers as prescient or present aggregate display as evidence of foresight. Calibration, where shown, appears only past a thirty-resolved floor and carries its noise caveat on its face. Per 6.06: this page is an aggregator of commitments, not a publisher vouching for content. Sealed commitments are opaque. For revealed content, each Kall is attributed to its source log; material that is unlawful or targets private individuals is removed from display on notice.

Join the federation

Publish a KNP-26 conformant hashlog — the protocol specifies the container, record shape, and mandatory public construction block; kalls.py is a working reference sealer. Host the log anywhere CORS-open (a raw GitHub URL works). Check it yourself before you ask anyone to read it: verify.html runs the conformance check in your own browser with no server contact, and knp_verify.py is standard-library Python that knows nothing about this desk. A CONFORMANT result is not our verdict on you; it is yours, reproducible by anyone. Then add yourself to nest_sources.json by pull request. Your seals stay yours; the Nest only reads.
