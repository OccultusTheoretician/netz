DIE LUECKE - the completeness audit

freshness — the completeness audit below

Every forecasting record in existence tests one assertion: were the calls that were made correct. That is an existence test. A Brier score is structurally incapable of seeing an event nobody called - a forecaster who calls only safe ground scores well and forecasts nothing, and no metric the ledger computes about itself can detect that.

This is the other assertion, the one auditors have long held to be the harder of the two: completeness. The desk's own collection confirms events daily across hostile sides. Against them it sets every row on the book, open and resolved, and asks one question per event - did any row name this ground?

An event confirmed by three hostile sides that no row names is a Luecke. Not a miss: a miss is a call that failed. A gap is ground the instrument's own eyes reported and the forecasting arm never spoke to.
