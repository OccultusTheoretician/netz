How to read this

Each row is one sealed projection: its id, the arm that issued it, the stated probability, and its status. Open rows have not reached their deadline; past-deadline rows await the weekly sitting; hit, miss and void are the sitting's verdicts, never edited after the fact.

Filter by arm, domain, rubric cohort or status; search the statement and resolution text; tap a row for its resolution, packet and report, then the remaining fields from the record itself.

Corrections are dated on the row and the superseded value is kept. Rejected rows are not here: their reasons live in each day's KKR report.

    Re-performance

    Nothing on this page is asserted that you cannot reproduce. The record is ledger.json; this viewer is a derived view of it.

    1. Clone the repository: git clone https://github.com/OccultusTheoretician/netz.git
    2. Hash the record with line endings normalised to LF and compare the first sixteen characters with the receipt below.
    3. Verify the OpenTimestamps receipt docs/ledger.json.ots against that digest with the ots client, or run python ots_anchor.py --status from the clone.
    4. Regenerate this page's index: python -c "import kkr; kkr.render_ledger()" writes forecasts/ledger_index.json; its row count must equal the record's.
